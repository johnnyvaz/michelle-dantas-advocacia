# Ancoragem de Preços — Técnica e Templates

## Por que ancorar funciona

O cérebro não avalia preços em termos absolutos — avalia em relação ao primeiro número que ouviu.
(Daniel Ariely — "Predictably Irrational", Capítulo 2)

Apresentar o preço real sem âncora = prospect compara com o que ele imaginava (sempre menor).
Apresentar após âncora alta = prospect compara com a âncora (sempre menor que a âncora).

**Resultado:** O mesmo preço parece caro ou barato dependendo do que veio antes.

---

## Sequência de ancoragem validada

### Etapa 1 — Âncora por custo de não resolver
```
"Só para ter uma base de comparação — quanto você gasta hoje
tentando resolver [problema] sem resultado?
[pausa — deixar o prospect calcular]
Isso é mais do que você pensa, né?"
```

### Etapa 2 — Âncora por alternativas de mercado
Apresentar concorrentes em ordem decrescente de preço:
```
"Para vocês terem uma ideia do que existe no mercado:
→ [Opção premium]: [preço alto]
→ [Opção conhecida]: [preço médio]
→ [Opção básica]: [preço baixo — mas sem o suporte que vimos]

E isso são coisas separadas — sem o que eu acabei de mostrar pra vocês."
```

**Regra:** Sempre apresentar a mais cara primeiro. A mais barata como última âncora ainda é mais cara que o produto (ou tem menos suporte).

### Etapa 3 — Bundling antes do preço
Recapitular tudo incluído antes de revelar o número:
```
"Então, para resumir o que está incluído:
→ [Item 1]
→ [Item 2]
→ [Item 3]
→ [Item 4 — o mais valioso]
→ [Suporte / comunidade]
O investimento para tudo isso é..."
```

**Por que funciona:** Cada item adiciona valor percebido. Quando o número final é revelado, o prospect está calculando a soma de todos os itens — não um único produto.

## Templates de âncora por produto

### Plataforma de Cursos
```
Âncora 1: Cursinhos online individuais separados — R$ 300 a R$ 600/mês cada
Âncora 2: Mentoria individual — R$ 500 a R$ 2.000/mês
Âncora 3: MBA / pós-graduação — R$ 800 a R$ 3.000/mês
→ Nosso preço: [X] por mês para tudo junto
```

### Serviço de avaliação / diagnóstico
```
Âncora 1: Psicólogo (10 sessões para o mesmo diagnóstico) — R$ 1.500 a R$ 3.000
Âncora 2: Coach executivo — R$ 500 a R$ 2.000/sessão
Âncora 3: Assessment DISC/MBTI + relatório — R$ 300 a R$ 800
→ Nossa avaliação: [X] — com relatório + plano de ação + recomendações
```

### Mentoria Individual
```
Âncora 1: Consultoria estratégica (mesma entrega) — R$ 5.000 a R$ 20.000
Âncora 2: Mentor de mercado (acesso indireto) — R$ 1.000 a R$ 5.000/hora
Âncora 3: Curso online (sem acompanhamento) — R$ 500 a R$ 2.000
→ Nossa mentoria: [X] — com acompanhamento direto + resultado garantido
```

## Pergunta pós-revelação do preço

Imediatamente após revelar o preço, antes de qualquer reação do prospect:
```
"Para tudo isso que a gente viu juntos, vocês acham que vale?"
```

**Por que funciona:** Força o prospect a avaliar o valor antes de processar o número.
Se ele disse "sim" aqui, a objeção de preço seguinte fica muito mais difícil de sustentar.

---

## Regras de ouro

1. **Nunca ser o primeiro a falar sobre preço** — deixar o prospect perguntar ou chegar à fase certa
2. **Nunca reduzir o preço duas vezes** — cria precedente de barganha sem fim
3. **Descontos sempre condicionais** — a um critério, não a uma negociação
4. **Nunca pedir desculpa pelo preço** — tom apologético transmite falta de confiança no valor
5. **Silêncio após o preço** — não preencher o silêncio com justificativas; deixar o prospect processar
