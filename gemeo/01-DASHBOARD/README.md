# 01-DASHBOARD — Painel executivo

KPIs **atual × meta** derivados do canon, mais o ritual semanal de revisão.

Arquivos típicos:
- `metrics-tracker.md` — tabela mensal dos KPIs (MRR, clientes, churn, uso do produto), com fonte e data.
- `checklist-semanal.md` — ritual semanal: rodar `/atualizar-gemeo`, revisar desvios, registrar decisões.
- `resumo-executivo.md` — um parágrafo por pasta (02–11) com status 🟢🟡🔴 e os campos do canon que o sustentam.

**Regra**: números vêm do canon; este painel só formata e compara com `metas`.
