# updates/ — Investor Updates Mensais

Um update por mês, no padrão de `99-TEMPLATES/relatorio-mensal.md` (seção "Versão para investidores").
Nome do arquivo: `update-AAAA-MM.md` (ex.: `update-2026-06.md`).
Os números entram **primeiro no canon** (`00-CANON/canon.yaml`), depois no update — nunca o contrário.
