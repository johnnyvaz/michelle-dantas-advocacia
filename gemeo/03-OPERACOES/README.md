# 03-OPERACOES — Cadeia de valor e workflows

Como o negócio entrega valor, ponta a ponta.
- `processos-chave.md` — processos macro (P1…Pn): aquisição → onboarding → entrega → suporte → renovação; por processo: dono, entrada/saída, métricas, riscos; e o **componente crítico** (cuja indisponibilidade exige post-mortem).
- `Workflows/workflows.md` — fluxos operacionais recorrentes (gatilho, passos, automação atual vs. possível).

Status de tarefas/sprints vem do Jira via `/atualizar-jira`.
