# 00-CANON — Fonte única da verdade

- [`canon.yaml`](./canon.yaml) — modelo numérico computável. **Todo número do corpus nasce aqui.**
- [`perguntas-oraculo.md`](./perguntas-oraculo.md) — perguntas que o oráculo deve responder; definem o escopo do canon.

## Regras
1. Prosa (pastas 01–10) **deriva** do canon e cita a origem — nunca contradiz.
2. Campos `(derivado)` são recalculados pelas skills `atualizar-*`, com a conta visível.
3. Valor sem fonte conectada → mantém e marca como "não atualizado". **Nunca chutar.**
4. Toda atualização anota `# via <fonte> em <AAAA-MM-DD>` e carimba `_meta.data_referencia`.
