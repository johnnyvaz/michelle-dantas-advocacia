# Ideias — Área (Pauta de Conteúdo)

> A área **Ideias** é o editor de pauta de `{{EMPRESA}}`: cruza o acervo do cérebro (pilares,
> posicionamento, voz do cliente, conteúdo já produzido) com sinais da web e entrega uma **pauta** para
> o dono escolher o que produzir.

## Papel

- **Pauta** (diária ou semanal, conforme a cadência de `calendario-editorial.md`): N ideias com gancho,
  formato sugerido, pilar, porquê e fonte.
- **Rodízio**: não repetir ideia, girar pilares e formatos.
- **Sinais**: tendência, notícia, pergunta recorrente de cliente; cada um com link e data.

> A área **gera a pauta e para**. Quem distribui é o `agente-social`; quem escreve a peça final é o
> `agente-copy` (ou `agente-conteudo-cursos`, se for aula); quem encena para gravar é o `agente-estudio`.

## Conteúdo durável da área

| Arquivo | Conteúdo |
|---|---|
| `persona.md` | postura do editor de pauta e a fronteira |
| `playbook.md` | fontes, anatomia da ideia, mix, formato da pauta |
| `heartbeat.md` | ciclo autônomo (OODA) + orçamento + fila `#area/ideias` |
| `memoria.md` | memória persistente (padrão PARA) |

## Regra de ouro

Nunca inventar tendência, manchete ou número de audiência. Pilar sem sinal da web fica "só acervo".
