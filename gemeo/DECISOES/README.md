# DECISOES/ — Business Decision Records (BDRs)

Uma decisão estratégica = um arquivo `D####-slug.md` (template: `0000-TEMPLATE.md`) com:
contexto, alternativas descartadas, posições do bloco decisor 🟢🟡🔴, **`canon_sha`**
(foto dos números no momento) e `campos_justificativa` (os números que sustentaram).

O oráculo usa este registro como **decision-guardian**: pergunta sobre tema já decidido
→ cita o BDR; números justificadores mudaram → sugere revisitar.

O índice em `../02-ESTRATEGIA/registro-de-decisoes.md` aponta para cá.
O campo **Resultado** de cada BDR alimenta a calibração dos perfis (08-PESSOAS).
