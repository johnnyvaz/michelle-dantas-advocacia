# 08-PESSOAS — Time e camada de adesão

O diferencial do gêmeo: prever se uma decisão será **abraçada** por quem decide/executa.

- `metodologia.md` — como levantar os perfis: níveis de confiança da fonte
  (questionário < entrevista < dossiê de perfil cognitivo).
- `Team/perfil-TEMPLATE.md` — modelo **bootstrap** (🟡) de perfil por decisor, com o
  **Intake** (perguntas que `/montar-gemeo` faz ao founder sobre a pessoa).
- `Team/perfil-completo-TEMPLATE.md` — modelo **medido** (🟢), alimentado por um dossiê
  de **perfil cognitivo** (dados → drivers → perfil → recomendações): forças a extrair, pontos
  cegos com plano de desenvolvimento, contexto de delegação para agentes e calibração
  previsão × desfecho. Fontes em `Team/<slug>/dossie/`.
- `Team/time-overview.md` — tabela do time espelhando `time[]`; folha fecha com `financeiro.custos.folha`.
- `Team/matriz-decisao-adesao.md` — por tipo de decisão (pricing, contratação, captação,
  pivot…), posição esperada de cada decisor 🟢🟡🔴. É o que o oráculo usa para prever adesão.
- `Cultura/valores-e-cultura.md` — valores com comportamento observável + antipadrão, e rituais.

**Regra**: perfil sem fonte da própria pessoa (entrevista/transcrição) é marcado como
*ilustrativo* 🟡. O oráculo cita a confiança do perfil ao prever adesão.
